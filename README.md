# 回此

等 Codex 处理任务时，回此帮你把思路留在当前的事上。目标体验是在安卓手机打开微信或小红书时，看到电脑正在做什么，并自主选择接着想这件事或继续打开应用。

| 内容 | 当前进度 |
| --- | --- |
| [Windows 小窗](codex-probe/README.md) | 跟随指定的真实 Codex 桌面会话，等待时显示当前请求和一条可选提示。 |
| [网页工作台](huici-demo/README.md) | 可体验等待、暂存念头和手机选择流程。已有同账号双浏览器同步验证。 |
| [浏览器扩展小样与开源复用记录](复用验证/README.md) | Chrome / Edge 小样展示 ChatGPT 网页等待提示。 |
| [产品需求与技术方案](回此-产品需求.md) | 首版目标是 Codex 桌面端和安卓。安卓系统触发、跨端同步当前任务和动态提问待实现。 |

在仓库根目录运行 `node --test codex-probe/record.test.mjs` 检查桌面接入。Windows 小窗与网页工作台的启动步骤分别见上表。
